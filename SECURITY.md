# Security Policy

## Reporting a Vulnerability

If you've found a security vulnerability, please report it responsibly. 

**Do not open a public issue.** Instead, please send an email to Yash Killamsetty (YashKiranK@gmail.com).

### What to include:
- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact if exploited.

We take security seriously and will respond as quickly as possible.
